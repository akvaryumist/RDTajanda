# Rasim Ajanda

Telefona kurulan kişisel ajanda uygulaması: takvim notları, tedarikçiler, ithalatlar ve müşteri fihristi.

- Kayıtlar yalnızca telefonda saklanır (bu klasörde veri yoktur).
- **Yedek** sekmesinden yedek alınıp WhatsApp/Drive'a gönderilir, gerektiğinde geri yüklenir.
- **Müşteriler → Excel'den yükle** ile Logo cari bakiye listesi içe aktarılır.
